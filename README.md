# EjerciciosSeleniumB.C
1. Compra básica en Demoblaze  
Automatizar la compra de un producto en Demoblaze. 
Debe capturar la página inicial, el detalle del producto, el carrito y la confirmación de 
compra. 
Además, debe capturar individualmente la tarjeta del producto y el botón Add to cart. 
El log debe registrar mínimo 8 eventos del proceso. 
2. Búsqueda de producto en Automation Exercise  
Ingresar a Automation Exercise, abrir la sección Products y buscar un producto. 
Debe capturar la página de productos, el resultado de búsqueda y un producto 
encontrado. 
Debe capturar individualmente el campo de búsqueda, el botón buscar y una tarjeta 
de producto. 
El log debe registrar la búsqueda realizada y si encontró resultados. 
3. Validación de login incorrecto en OrangeHRM  
Ingresar credenciales incorrectas en OrangeHRM Demo. 
Debe capturar la pantalla inicial del login, el formulario diligenciado y el mensaje de 
error. 
Debe capturar individualmente el campo usuario, campo contraseña, botón login y 
mensaje de error. 
El log debe registrar inicio, ingreso de datos, intento de login y error mostrado. 
4. Consulta en Wikipedia  
Buscar la palabra Selenium en Wikipedia. 
Debe capturar la página principal, el resultado de búsqueda y el título del artículo. 
Debe capturar individualmente la barra de búsqueda, el botón de búsqueda y el título 
principal. 
El log debe registrar la palabra buscada, la URL cargada y el resultado encontrado. 
5. Agregar dos productos al carrito en Demoblaze  
Seleccionar dos productos diferentes y agregarlos al carrito. 
Debe capturar cada etapa: producto 1, producto 2, carrito con ambos productos y 
total. 
Debe capturar individualmente cada nombre de producto y el total del carrito. 
El log debe registrar cada producto agregado. 
6. Formulario de contacto en Automation Exercise  
Ingresar a Contact Us y diligenciar el formulario. 
Debe capturar la página de contacto, el formulario lleno y el mensaje final. 
Debe capturar individualmente los campos nombre, email, asunto, mensaje y botón 
enviar. 
El log debe registrar cada campo diligenciado. 
7. Validación de menú principal en Demoblaze  
Ingresar a Demoblaze y validar las opciones del menú superior. 
Debe capturar la página inicial y cada menú seleccionado: Home, Contact, About us, 
Cart y Log in. 
Debe capturar individualmente cada opción del menú. 
El log debe registrar cada clic realizado. 
8. Filtrado por categoría en Demoblaze  
Seleccionar una categoría como Phones, Laptops o Monitors. 
Debe capturar la página inicial, la categoría seleccionada y los productos mostrados. 
Debe capturar individualmente el enlace de la categoría y una tarjeta de producto. 
El log debe registrar la categoría seleccionada y la cantidad de productos visibles. 
9. Validación de productos visibles en Automation Exercise  
Abrir la sección Products y verificar que existan productos cargados. 
Debe capturar la pantalla completa de productos y mínimo tres tarjetas individuales. 
Debe capturar nombre, precio e imagen de un producto. 
El log debe indicar cuántos productos fueron detectados. 
10. Registro de usuario en Automation Exercise  
Iniciar el proceso de registro de un usuario. 
Debe capturar la página de inicio, el formulario de registro y los datos ingresados. 
Debe capturar individualmente el campo nombre, campo correo y botón signup. 
El log debe registrar el inicio del registro y los datos principales usados, sin guardar 
contraseñas reales. 
11. Validación de carrito vacío en Demoblaze  
Ingresar directamente al carrito sin agregar productos. 
Debe capturar la página inicial, el ingreso al carrito y el carrito vacío. 
Debe capturar individualmente el botón Cart y la tabla del carrito. 
El log debe registrar que no se encontraron productos agregados. 
12. Compra con datos incompletos en Demoblaze  
Agregar un producto al carrito e intentar finalizar la compra dejando campos vacíos. 
Debe capturar producto, carrito, formulario de compra y alerta generada. 
Debe capturar individualmente el botón Place Order, el formulario y la alerta. 
El log debe registrar el intento fallido de compra. 
13. Búsqueda sin resultados en Automation Exercise  
Buscar un producto inexistente, por ejemplo ProductoXYZ123. 
Debe capturar la pantalla de búsqueda y el resultado obtenido. 
Debe capturar individualmente el campo de búsqueda y el mensaje o zona de 
resultados. 
El log debe indicar que la búsqueda no devolvió coincidencias visibles. 
14. Validación de elementos del login en OrangeHRM  
Abrir OrangeHRM Demo y validar que el formulario de login cargue correctamente. 
Debe capturar la pantalla completa del login. 
Debe capturar individualmente logo, campo usuario, campo contraseña, botón login 
y enlace de recuperación. 
El log debe registrar que cada elemento fue encontrado. 
15. Inicio de sesión correcto en OrangeHRM  
Ingresar con credenciales válidas en OrangeHRM Demo. 
Debe capturar pantalla de login, datos ingresados y panel principal. 
Debe capturar individualmente el botón login, el título del dashboard y el menú 
lateral. 
El log debe registrar autenticación exitosa y carga del panel. 
16. Validación de título de artículo en Wikipedia  
Buscar un tema asignado por el instructor, por ejemplo Java, Software testing o SENA. 
Debe capturar la búsqueda, el resultado y el encabezado del artículo. 
Debe capturar individualmente el título, primer párrafo y tabla lateral si existe. 
El log debe registrar el tema consultado y el título obtenido. 
17. Captura de evidencias con fecha y hora  
Automatizar cualquier flujo en Demoblaze o Automation Exercise. 
Todas las capturas deben guardarse con fecha y hora en el nombre del archivo. 
Debe incluir mínimo 5 capturas por etapas y 5 capturas de elementos individuales. 
El log debe registrar la ruta exacta de cada evidencia creada. 
18. Reporte de navegación completa  
Realizar una navegación por mínimo cinco secciones de una página seleccionada. 
Puede ser Demoblaze, Automation Exercise o Wikipedia. 
Debe capturar cada sección visitada. 
Debe capturar individualmente un elemento importante de cada sección. 
El log debe registrar URL, nombre de sección y hora de visita. 
19. Validación de alerta en Demoblaze  
Realizar una acción que genere una alerta, por ejemplo agregar un producto al carrito. 
Debe capturar antes de la acción, después del clic y, si es posible, el estado posterior 
a la alerta. 
Debe capturar individualmente el botón que genera la alerta y el producto 
seleccionado. 
El log debe registrar el texto de la alerta capturada.
